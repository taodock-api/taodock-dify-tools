# Privacy Disclosure

The TaoDock Media plugin sends the configured API key and the fields required by each selected tool to `https://taodock.com/v1`. These fields can include model IDs, prompts, generation settings, and video task IDs. It also reads the models authorized for the key and the public TaoDock model catalog.

The plugin does not add analytics and does not intentionally persist API keys, prompts, generated media, or API responses. Dify manages provider credentials and may retain workflow inputs, outputs, files, and logs according to the configuration of the Dify deployment.

TaoDock processes API traffic under the policy at https://taodock.com/privacy-policy. Only submit data that you are authorized to process.
